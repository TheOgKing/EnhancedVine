# EnhancedVine
A specialized mobile browser for Amazon Vine built with React Native and Expo, featuring custom script injection, advanced theming, and an enhanced search interface.

EnhancedVine is a feature-rich mobile client designed to optimize the Amazon Vine user experience. By leveraging a high-performance WebView and a modular script injection system, it provides tools and interface improvements not available in a standard browser.

Key Features
Modular Script System: Toggleable enhancements including an ETV (Estimated Tax Value) Tracker, Infinite Scroll, EZ Order, and a Review Countdown.

Advanced UI Theming: Support for multiple visual styles (Modern, Classic, Modern Light) that inject custom CSS directly into the Vine interface for a cleaner look.

Search Management: A dedicated search term persistence system with a quick-access scrollable bar or dropdown for saved queries.

Custom Navigation: An animated, gesture-driven bottom tab bar with dynamic tab reordering capabilities.

Developer Toolkit: Integrated element inspector, resolution simulator, and debug logging for real-time interface testing.

Global Support: Pre-configured support for multiple Amazon regions including .com, .ca, .co.uk, .de, and more.
